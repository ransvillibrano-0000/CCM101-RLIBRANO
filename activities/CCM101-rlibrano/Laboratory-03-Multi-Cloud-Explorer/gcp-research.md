# Google Cloud Platform (GCP) Research

**Brief Overview**
Google Cloud Platform (GCP) is a suite of cloud computing services that runs on the same infrastructure that Google uses internally for its end-user products, like Google Search and YouTube.

**Global Infrastructure**
GCP is built on a highly advanced, global fiber-optic network consisting of Regions and Zones designed to deliver high throughput, low latency, and sustainable data centers.

**Cloud Management Console**
The Google Cloud Console provides a web-based, highly intuitive GUI to provision, configure, and monitor cloud resources, alongside a powerful Cloud Shell for CLI access.

**Four (4) Core Services**
1. **Google Compute Engine (GCE):** Customizable virtual machines.
2. **Google Cloud Storage (GCS):** Unified object storage.
3. **Google Kubernetes Engine (GKE):** Managed environment for deploying containerized apps.
4. **BigQuery:** Serverless, highly scalable enterprise data warehouse.

**Three (3) Advantages**
1. Industry-leading capabilities in Artificial Intelligence, Machine Learning, and Data Analytics.
2. Best-in-class support for Kubernetes and containerized workloads.
3. Fast global network utilizing Google's proprietary infrastructure.

**Typical Enterprise Use Cases**
GCP is frequently selected by AI research companies, data-heavy analytics firms, and developers heavily utilizing containerization (Kubernetes) and open-source stacks.
