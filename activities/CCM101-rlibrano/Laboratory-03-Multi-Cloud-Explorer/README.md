# Mission 3: Become a Multi-Cloud Explorer

## Mission Overview
As part of the Cloud Evaluation Team at CloudNova Technologies, this mission explores the core services, infrastructure, and use cases of the top three public cloud providers: AWS, Microsoft Azure, and Google Cloud Platform (GCP). The goal is to evaluate their strengths and formulate professional recommendations for enterprise clients based on specific business requirements.

## Linux Investigation
Using KillerCoda, I investigated a local Linux server environment:
- **Operating System:** Ubuntu 24.04 LTS
- **CPU Information:** 1 CPU Core, x86_64 Architecture
- **Memory:** 1903 MB Total
- **Disk Space:** 13G Available on root partition

**Cloud Migration Counterparts:**
If this Linux server were migrated to the cloud, the exact virtual machine services that could host it are:
- **AWS:** Amazon Elastic Compute Cloud (EC2)
- **Azure:** Azure Virtual Machines
- **GCP:** Google Compute Engine (GCE)
