## Service Analysis Questions
**Which cloud provider offers the broadest range of services?**
AWS offers the broadest and deepest range of cloud services. 
Because they were the first major provider, they have had the 
most time to develop over 200 fully featured services.

**Which provider best integrates with Microsoft technologies?**
Microsoft Azure provides the best integration with Microsoft technologies. 
It seamlessly connects with Windows Server, Active Directory, and Microsoft 365, 
making it highly efficient for organizations already using these tools.

**Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform (GCP) is the strongest in AI and Kubernetes. Google originally 
developed Kubernetes, and their deep expertise in machine learning is reflected in 
proprietary tools like TensorFlow and BigQuery.

**Which cloud platform would you personally choose and why?**
As a 4th-year IT student focusing on web and game development, I would choose AWS. 
Its extensive documentation, massive community support, and highly scalable EC2 and 
S3 services make it the most versatile platform for deploying personal projects and 
scaling web applications.
